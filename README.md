# 괴물 세상의 케이크 가게 🎂

> **NAN 2026 (NHN Game×AI 해커톤) 사전과제**
> 손님의 **애매한 주문**을 대화로 파고들어, 그 진짜 마음을 케이크로 완성하는 캐주얼 게임.

괴물 손님이 찾아와 두루뭉술한 주문을 남깁니다 — *"바다 느낌 나게 해줘"*, *"생일인데… 좀 특별하게"*.
정답은 손님 머릿속에만 있습니다. 플레이어는 **채팅으로 질문**해 단서를 좁히고, 시트를 굽고 색과
토핑을 올려 케이크를 냅니다. 손님의 만족도만큼 매출이 쌓이죠.

<p align="center"><em>"애매함을 읽어내는 것" 그 자체가 재미이자, 이 게임이 AI로 굴러가는 이유입니다.</em></p>

## 이 게임의 한 줄

**LLM을 빼면 게임이 성립하지 않습니다.** 손님의 대사·성격·힌트는 실시간 LLM이 연기하고,
채점은 결정적 코드가 담당합니다. "AI가 핵심 재미를 만드는가"라는 심사 기준을 정면으로 겨냥한 설계예요.

## 어떻게 노나

1. **손님 등장** — 괴물이 애매한 주문을 던진다.
2. **대화** — 채팅으로 질문해 원하는 맛·색·토핑·문구를 좁힌다. (손님은 쉽게 정답을 말해주지 않는다.)
3. **제작** — 시트 반죽 → 굽기 → 색내기 → 생크림 → 토핑 → 데코 → 레터링.
4. **완성** — 손님이 케이크를 보고 반응. 만족도 점수만큼 매출이 오른다.
5. 손님을 이어 받다가 하루가 끝나면 **오늘 매출**을 정산.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173  — API 키 없이도 mock으로 끝까지 플레이 가능
```

실제 LLM(손님 대화)까지 로컬에서 켜려면 터미널 2개:

```bash
npm run api        # localhost:3001 — 서버리스 함수(chat/judge)를 로컬에서 뜬다
npm run dev        # localhost:5173 — 프론트
# 사전: .env.local 에 OPENAI_API_KEY 설정 (.env.example 참고)
```

## 기술 스택

- **프론트**: React 18 + Vite (순수 JS)
- **백엔드**: Vercel 서버리스 함수 (`/api`) — 대화(`chat`)·판정(`judge`)
- **LLM**: OpenAI(기본 `gpt-4o-mini`) / Anthropic 전환 가능 — `api/_llm.js` 한 곳에서 추상화
- **배포**: Vercel
- **아트**: 직접 그린 손그림을 PIL로 누끼/색틴트 처리한 PNG

작게·확실히·**완성 우선**. TypeScript, 복잡한 채점 루브릭, 최적화, 리더보드 같은
과한 스펙은 사전과제 범위에서 의도적으로 뺐습니다. 끝에서 끝까지 도는 것을 먼저, 폴리시는 나중에.
