wierdcake.zip — 목업 v2 · 실제 에셋 적용

위키 게임 플로우 확정 스펙 반영 · 스티커 오버레이 · 390×844
그림은 전부 public/assets의 실제 PNG. UI만 흰 채움 + 잉크 아웃라인 2.2px. 점수 숫자는 어디에도 노출하지 않는다 — 별점 + 코인만.
배경 맛 시트
확정 규칙 — 스테이지 3개 × 손님 5명 · 통과선 60점(별 3개) · 코인 = 점수 그대로 · 질문 1–10턴 −2점/턴, 11–15턴 코인 구매(감점 없음) · 하트 최대 5 · 제작 6단계(굽기는 연출) ·
튜토리얼 제안 버블은 무료(턴 소모·감점 없음, 스테이지 1 한정).
버튼 규칙 — 다시만들기 = 이 단계 처음으로 / 되돌리기(↺) = 마지막 동작 하나 취소. ↺는 여러 개를 쌓는 단계(생크림·토핑)에만 둔다.
⚠ 실측 후 확정 — 질문 코인 단가(30/턴), 재료 언락 단가(120). 화면 숫자는 자리표시.
에셋 — public/assets의 실제 PNG 사용. 파일이 없으면 onerror로 조용히 비워진다.
⚠ 없는 에셋 1개 — ing_vanilla.png. 바닐라만 재료 아이콘이 없어 임시로 cream_vanilla.png로 대체했다. 그려서 넣으면 자동 반영됨.
